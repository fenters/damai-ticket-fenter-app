# Web 模式使用说明

![Web 模式界面](../../web_image.png)

## 概述

Web 模式通过 Selenium 驱动 Chrome 浏览器操作大麦网网页版，适用于 PC 端抢票场景。

## 前置条件

- Python 3.7+
- Chrome 浏览器
- ChromeDriver（版本需与 Chrome 匹配）
- 依赖：`pip install -r requirements.txt`

## 使用步骤

### 1. 启动 GUI v2

```bash
python start_gui_v2.pyw
```

### 2. 切换到 Web 模式

在 GUI 顶部点击 **Web** 切换按钮，左侧面板自动切换为网页配置内容。

### 3. 配置抢票参数

- **目标 URL**：输入大麦网演出详情页链接（如 `https://detail.damai.cn/...`）
- **关键词**：演出名称（可选，用于日志标识）
- **城市**：演出所在城市
- **日期**：选择演出场次时间
- **价格档位**：可选，填入期望价格

### 4. 开始抢票

1. 点击 **检测环境** 验证 ChromeDriver 可用
2. 点击 **开始抢票**
3. 首次使用需扫码登录（浏览器自动打开大麦网）
4. 登录后 Cookie 自动保存，后续无需重复登录
5. 脚本会自动执行抢票流程

## 配置管理

- App 和 Web 模式共用同一配置文件：项目根目录 `config.json`
- 可在 GUI 中点击 **保存配置** / **加载配置** 管理
- 配置包含 `target_url`、`keyword`、`city`、`date`、`price` 等字段
- 点击 **保存配置** 写入根目录 `config.json`，下次启动自动加载

## 登录说明

| 项目 | 说明 |
|------|------|
| **首次使用** | 点击开始抢票后自动打开浏览器，在大麦网完成扫码登录 |
| **再次使用** | Cookie 自动加载（`damai_cookies.pkl`），无需重复登录 |
| **状态检测** | 启动时自动验证 Cookie 有效性，失效则提示重新登录 |

### `damai_cookies.pkl` 会⾃动更新吗？

**不会自动更新。** `damai_cookies.pkl` 仅在以下时机写入：

1. **首次登录成功**后自动保存
2. **主动清除 Cookie** 后重新登录时覆盖保存

如果在大麦网网页端手动退出登录或 Cookie 过期，`damai_cookies.pkl` **不会自动删除或刷新**。此时需在 GUI 中手动清除登录状态，重新开始抢票流程以触发重新登录。

## 注意事项

1. Chrome 和 ChromeDriver 版本必须匹配
2. 网络不稳定可能导致页面加载超时
3. 脚本到订单提交页即结束，需手动完成支付
4. 大麦网页版可能更新页面结构，如遇按钮识别失败可反馈
